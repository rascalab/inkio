# 어댑터 마이그레이션

어댑터 API는 v0.0.5에서 제거됐습니다. 지금은 옵션을 `@inkio/editor` 또는
`@inkio/simple`의 `Editor`에 직접 전달하세요.

```tsx
<Editor
  hashtagItems={hashtagItems}
  mentionItems={mentionItems}
  onWikiLinkClick={onWikiLinkClick}
/>
```

현재 옵션은 [컴포넌트 문서](/components/)에 있습니다. 이전 어댑터의 옵션과 예제는
[v0.0.3 어댑터 문서](/versions/v0.0.3/adapter/)를 보세요.
