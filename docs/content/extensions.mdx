# 확장

inkio 확장은 두 층으로 나뉩니다.

- `@inkio/core`
  - callout
  - details/toggle
  - table
  - keyboard shortcuts
- `@inkio/advanced`
  - slash command
  - block handle
  - mention
  - hashtag
  - wiki link
  - bookmark
  - comment

## 권장 시작점

- classic editor가 필요하면 `@inkio/simple`
- notion-like editor가 필요하면 `@inkio/editor`
- low-level 조합이 필요하면 `@inkio/core` 또는 `@inkio/advanced`

## 조합 예시

```tsx
import { Editor } from '@inkio/core';
import { getDefaultExtensions } from '@inkio/advanced';
import '@inkio/core/style.css';
import '@inkio/advanced/style.css';

const extensions = getDefaultExtensions({
  hashtagItems: ({ query }) => [{ id: query || 'inkio', label: `#${query || 'inkio'}` }],
});

export function Page() {
  return <Editor extensions={{ items: extensions, replace: true }} content="<p>Hello inkio</p>" />;
}
```

`@inkio/advanced/style.css`는 확장 스타일만 추가합니다. `@inkio/editor/style.css`를 이미 가져왔다면 별도로 가져오지 마세요.

Markdown 문자열 입출력은 코어와 프리셋 모두 `extensions={[Markdown]}`으로 [등록](/serialization/)합니다. `MarkdownPaste`는 클립보드 붙여넣기를 변환하는 별도 확장입니다.

## 멘션 (Mention)

`@` 트리거로 사용자 등을 멘션합니다. `mentionItems`는 `({ query }) => MentionItem[]` 형태의 함수로,
사용자가 `@` 뒤에 입력한 `query`에 맞는 항목을 반환합니다. 동기/비동기 모두 가능합니다.

```ts
interface MentionItem {
  id: string;
  label: string;
  [key: string]: unknown;
}
```

```tsx
import { Editor } from '@inkio/editor';

<Editor
  mentionItems={async ({ query }) => {
    const users = await searchUsers(query);
    return users.map((user) => ({ id: user.id, label: user.name }));
  }}
/>
```

해시태그도 동일한 패턴이며, `#` 트리거와 `hashtagItems`를 사용합니다. 기본 확장에는 두 노드가
항상 포함되어 이미 저장된 멘션과 해시태그를 표시할 수 있습니다. 목록 함수를 생략하면 제안 팝업은 열리지 않습니다.

```tsx
<Editor
  hashtagItems={({ query }) => [
    { id: query || 'inkio', label: `#${query || 'inkio'}` },
  ]}
/>
```

`@inkio/core` + `@inkio/advanced` 직접 조합 시에는 `getDefaultExtensions`에 동일한 옵션을 전달합니다.

```tsx
const extensions = getDefaultExtensions({
  mentionItems: async ({ query }) => searchUsers(query),
});
```

## 슬래시 커맨드 (Slash Command)

`/`를 입력하면 명령 메뉴가 열립니다. 기본 명령에는 헤딩, 리스트, 표, 코드 블록, 콜아웃,
토글 리스트, 목차, 이미지 등이 포함됩니다. 두 가지 방식으로 커스터마이즈할 수 있습니다.

`transformSlashCommands`는 기본 명령 배열을 받아 가공한 뒤 반환합니다. 일부 명령만 추가하거나
제거할 때 적합합니다. 전체 목록을 받으며, 반환된 항목은 이후 `query`로 필터링됩니다.

```tsx
import { Editor } from '@inkio/editor';
import type { SlashCommandItem } from '@inkio/advanced';

<Editor
  transformSlashCommands={(defaults) => {
    const custom: SlashCommandItem = {
      id: 'today',
      label: 'Today',
      description: '오늘 날짜 삽입',
      command: ({ editor, range }) => {
        editor
          .chain()
          .focus()
          .deleteRange(range)
          .insertContent(new Date().toLocaleDateString())
          .run();
      },
    };
    return [custom, ...defaults];
  }}
/>
```

`slashCommands`는 기본 명령 대신 사용할 목록을 `(query: string) => SlashCommandItem[] | Promise<SlashCommandItem[]>`
형태로 제공합니다. 둘을 함께 넘기면 `transformSlashCommands`는 이 목록을 가공합니다.
어느 경우든 마지막에 `isAvailable`을 검사하고, `id` 또는 `label`에 검색어가 포함된 항목을
대소문자와 공백을 무시해 최대 50개까지 표시합니다. 직접 필터링할 필요는 없습니다.

```tsx
<Editor
  slashCommands={() => myCommands}
/>
```

`SlashCommandItem`의 `isAvailable?: (editor) => boolean`으로 특정 명령의 노출 조건을 지정할 수 있습니다.

## 위키 링크 (Wiki Link)

`[[페이지 이름]]` 문법으로 인라인 위키 링크를 만듭니다. 닫는 `]]`를 입력하는 순간
입력 규칙(input rule)이 발동해 텍스트가 위키 링크 노드로 치환되며, `[[...]]`가 포함된 텍스트를
붙여넣어도 동일하게 변환됩니다.

`wikiLinkItems`를 넘기면 `[[`를 입력하는 즉시 페이지 목록 팝업이 열리고, 이어서 입력한 글자가
`query`로 전달됩니다(공백 포함). 항목을 고르면 그 항목의 `id`가 링크 대상(`href`)이 되고 칩에도
그대로 표시되므로, 보통 `id`와 `label`에 같은 페이지 이름을 넣습니다. 목록에 없는 이름도
`]]`까지 입력하면 링크가 됩니다. `wikiLinkItems`가 없으면 팝업 없이 `]]` 입력으로만 변환됩니다.

`@inkio/editor`에서는 `wikiLink` prop으로 켜고 끄며 기본값은 `true`입니다.
링크 클릭 동작은 `onWikiLinkClick` 콜백으로 처리합니다. 콜백을 지정하지 않으면 링크는
클릭할 수 없는 텍스트로만 표시됩니다.

```tsx
import { Editor } from '@inkio/editor';

<Editor
  wikiLinkItems={async ({ query }) => {
    const pages = await searchPages(query);
    return pages.map((page) => ({ id: page.title, label: page.title }));
  }}
  onWikiLinkClick={(href) => {
    router.push(`/wiki/${encodeURIComponent(href)}`);
  }}
/>
```

`href`는 `[[...]]` 안에 입력한 페이지 이름 문자열입니다. 안전하지 않은 URL은 클릭이 무시됩니다.
`javascript:`/`data:`/`vbscript:` 같은 위험 target은 입력·붙여넣기·HTML 파싱 단계에서 노드 생성이 거부됩니다.

## 북마크 (Bookmark)

URL을 링크 미리보기 카드로 렌더링하는 블록 노드입니다. `@inkio/editor`에서는 `bookmark` prop으로
설정하며, `false`를 전달하면 비활성화됩니다.

```ts
bookmark?: false | { onResolveBookmark?: (url: string) => Promise<BookmarkPreview> };
```

북마크는 `setBookmark` 커맨드로 삽입합니다.

```tsx
editor.commands.setBookmark({ url: 'https://example.com' });
```

`onResolveBookmark`는 URL을 받아 미리보기 데이터(`BookmarkPreview`)를 반환합니다.
편집 중 `setBookmark`로 삽입한 북마크에 미리보기 데이터가 없으면 조회를 시도합니다.
조회 함수도 저장된 미리보기도 없으면 URL 링크만 표시합니다.

```ts
interface BookmarkPreview {
  title?: string;
  description?: string;
  image?: string;
  favicon?: string;
}
```

```tsx
<Editor
  bookmark={{
    onResolveBookmark: async (url) => {
      const meta = await fetchOpenGraph(url); // 직접 구현하는 메타데이터 조회
      return {
        title: meta.title,
        description: meta.description,
        image: meta.ogImage,
        favicon: meta.favicon,
      };
    },
  }}
/>
```

> 미리보기는 편집 중 직접 추가한 웹 북마크에 대해서만 조회를 시도합니다. 문서를 열거나
> 협업으로 받은 북마크는 자동 조회하지 않습니다. 실제 Open Graph 조회는 앱이 구현합니다.
> 서버에서 조회한다면 URL을 비신뢰 입력으로 취급하고 허용 목적지, DNS 결과,
> 리다이렉트, 타임아웃 및 응답 크기를 서버에서 제한하세요.

## TocBlock (인라인 목차)

`@inkio/core`에 기본 포함됩니다. 문서 안에 Notion 스타일의 인라인 목차 블록을 삽입합니다.

> **참고:** 에디터 외부에 오버레이 미니맵 형태로 표시하려면 `<ToC>` 컴포넌트를 사용하세요. [컴포넌트 문서 참고](/components#option-2-toc-컴포넌트-오버레이-미니맵)

- `/toc` 슬래시 커맨드로 삽입 (`@inkio/advanced` SlashCommand 필요)
- 헤딩이 추가/수정/삭제되면 자동으로 업데이트됩니다
- 항목 클릭 시 해당 헤딩으로 스크롤됩니다
- 배경/테두리 없는 Notion 스타일 미니멀 디자인 (텍스트 링크만)
- 헤딩이 없으면 muted 플레이스홀더 표시: "Add headings to see the table of contents."

비활성화하려면 `getExtensions`에 `tocBlock: false`를 전달합니다:

```tsx
import { Editor, getExtensions } from '@inkio/core';

const extensions = getExtensions({ tocBlock: false });
<Editor extensions={{ items: extensions, replace: true }} />
```

## CodeBlock (코드 블록)

`@inkio/core`에 기본 포함되며, `lowlight` 기반 구문 강조를 제공합니다. 37개의 일반적인 언어를 지원하며, 언어 문법은 문서에 실제로 등장한 것만 lazy-load되므로 코드 블록이 없는 페이지는 하이라이팅 비용을 내지 않습니다.

- **편집 모드**: 언어 선택기와 복사 버튼
- **읽기 전용 노드 뷰**: 복사 버튼과 언어 배지(언어를 지정한 경우). 정적 HTML에는 이 UI가 없습니다.
- `tsx` / `jsx`는 모두 `typescript`의 별칭으로 처리됩니다

코드 블록을 비활성화하려면 `getExtensions`에 `codeBlock: false`를 전달합니다.

## 커스텀 확장

코어와 프리셋의 `Editor`, 뷰어, `useInkioEditor`와 `useInkioCollaborativeEditor`는 같은 `extensions` 규칙을 사용합니다. 각 표면의 기본 목록은 다를 수 있습니다.

### 타입

```ts
import type { CoreExtensions } from '@inkio/core';

type ExtensionsInput =
  | Readonly<CoreExtensions>
  | { items: Readonly<CoreExtensions>; replace?: boolean };
```

- **배열 또는 `{ items }`**: 기본 확장에 추가합니다. 이름이 같으면 마지막으로 전달한 확장이 우선합니다. `[]`는 아무것도 추가하지 않습니다.
- **`{ items, replace: true }`**: 기본 확장을 전부 교체합니다. `getExtensions({ tocBlock: false })`처럼 일부 기본 확장을 제외한 목록을 직접 구성했을 때 이 형식을 사용하세요. 빈 `items`도 그대로 적용되므로 실제 에디터를 만들려면 문서 스키마에 필요한 노드를 직접 포함해야 합니다.
- 협업 훅은 위 규칙으로 결정된 목록에서 일반 실행 취소 확장을 제거한 뒤, 연결된 문서에 필요한 협업 확장을 설치합니다.

### 예시: 확장 추가

```tsx
import { Editor } from '@inkio/editor';
import { Markdown } from '@inkio/core/markdown';

<Editor
  extensions={[Markdown]}
  onCreate={editor => console.log(editor.markdown)}
/>
```

> inkio는 `@tiptap/*`을 외부 의존성으로 사용합니다. Tiptap 확장을 직접 설치할 때는
> inkio가 사용하는 버전에 맞춰 서로 다른 런타임이 중복 설치되지 않게 하세요.

### 예시: 기본 확장 전체 교체

```tsx
import { Editor, getExtensions } from '@inkio/core';

const items = getExtensions({ codeBlock: false, table: false });
<Editor extensions={{ items, replace: true }} />
```

## 기능 토글 (`@inkio/editor` 전용)

`@inkio/editor`의 `Editor` 컴포넌트는 주요 확장을 prop으로 켜고 끌 수 있습니다.

| Prop          | 기본값  | 설명                    |
| ------------- | ------- | ----------------------- |
| `blockHandle` | `true`  | 블록 드래그 핸들        |
| `wikiLink`    | `true`  | `[[위키링크]]` 문법     |
| `table`       | `true`  | 표                      |
| `callout`     | `true`  | 콜아웃 블록             |
| `toggleList`  | `true`  | 토글(접기/펼치기) 리스트 |

```tsx
<Editor
  blockHandle={false}
  wikiLink={false}
/>
```

### 블록 메뉴와 순서 바꾸기

`@inkio/editor`의 `blockHandle`은 드래그 핸들과 블록 메뉴를 함께 켜고 끕니다.
`editable={false}`와 Viewer에서는 둘 다 동작하지 않습니다.

- **마우스**: 블록 옆의 점 여섯 개 핸들을 눌러 메뉴를 열거나, 핸들을 끌어 블록을 옮깁니다.
- **터치**: 블록을 한 번 탭해 핸들을 표시하고, 핸들을 다시 탭해 메뉴를 엽니다.
  핸들을 끌어서 옮길 수도 있습니다. 본문에서 시작한 스와이프는 평소처럼 스크롤됩니다.
- **키보드**: 블록 안에서 `Shift+F10`을 누릅니다. 화살표로 항목을 이동하고
  Enter로 실행하거나 Esc로 에디터에 돌아옵니다.

메뉴에서 삭제·복제하거나, 텍스트를 지원하는 블록의 유형을 바꿀 수 있습니다.
드래그 없이 옮기려면 **위로 한 칸** 또는 **아래로 한 칸**을 선택하세요. 리스트
항목은 같은 리스트 안에서 움직이며, 이동할 수 없는 방향은 표시하지 않습니다.
드래그 중에는 블록의 너비와 줄바꿈을 유지한 미리보기와 삽입선이 표시됩니다.
화면 또는 편집 영역 위·아래 가장자리에 핸들을 끌면 자동으로 스크롤합니다.

문구는 `ui.messages.core.blockHandle`(예: `moveUp`, `moveDown`), 아이콘은
`ui.icons`로 바꿀 수 있습니다. 블록 메뉴에는 툴바의 `items`나 `children`에
해당하는 옵션이 없습니다. 직접 확장을 조합할 때는 `@inkio/advanced/block-handle`의
`BlockHandle.configure({ dragHandleWidth: 28 })`로 핸들 너비를 설정할 수 있습니다.
