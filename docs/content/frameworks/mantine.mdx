# Mantine 통합

Mantine 안에서 Inkio를 쓸 때는 high-level package부터 시작하는 편이 가장 안정적입니다.

```bash
pnpm add @mantine/core @inkio/editor react react-dom
```

스타일:

```tsx
import '@mantine/core/styles.css';
import '@inkio/editor/minimal.css';
import './inkio-mantine.css';
```

## 디자인 토큰 연결

Inkio의 UI는 모두 `--inkio-*` CSS 변수로 그려집니다. 아래 파일을 Inkio CSS **다음에** 불러오면 폰트, primary 색, radius, 그림자, 배경·글자·테두리 색이 Mantine 테마(`createTheme`)를 그대로 따릅니다. Mantine 변수는 색 스킴에 따라 값이 바뀌므로 라이트와 다크(`--inkio-dark-*`) 토큰을 같은 변수에 연결합니다.

## 다크 모드 동기화

Mantine은 `<html data-mantine-color-scheme>` 속성으로, Inkio는 `theme` prop(또는 `.dark` 클래스)으로 다크 모드를 판단합니다. 위에서 연결한 색은 Mantine을 바로 따라가지만 콜아웃, 멘션, 코드 하이라이트처럼 Inkio 고유 색은 `theme`을 넘겨야 함께 바뀝니다.

```tsx
import { useComputedColorScheme } from '@mantine/core';
import { Editor } from '@inkio/editor';

export function MyEditor() {
  const scheme = useComputedColorScheme('light');
  return <Editor theme={scheme} />;
}
```

`Viewer`도 같은 방식으로 `theme`을 받습니다.

## Modal·Drawer 안에서 쓰기

Mantine `Modal`은 z-index 200 위에 그려지고, Inkio 메뉴의 기본 레이어는 150입니다. 위 파일의 `--inkio-layer-*` 연결이 Inkio 팝업을 Mantine popover 레벨(300)로 올리므로 모달 안에서도 슬래시 메뉴, 버블 메뉴, 테이블 메뉴가 모달 위에 열립니다. 이미지 에디터 모달은 Mantine overlay 레벨(400) 위로 올라갑니다.

## 연결하지 않는 토큰

콜아웃, 멘션, 해시태그, 위키링크, 댓글 하이라이트, 코드 블록 배경은 Inkio의 라이트·다크 팔레트를 그대로 씁니다. Mantine 색으로 바꾸려면 같은 방식으로 라이트 토큰과 `--inkio-dark-*` 토큰을 함께 덮어씁니다.

```css
.inkio {
  --inkio-mention-bg: var(--mantine-primary-color-light);
  --inkio-mention-text: var(--mantine-primary-color-light-color);
  --inkio-dark-mention-bg: var(--mantine-primary-color-light);
  --inkio-dark-mention-text: var(--mantine-primary-color-light-color);
}
```
