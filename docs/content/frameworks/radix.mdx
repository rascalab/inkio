# Radix UI 통합

Radix Themes 안에서는 `@inkio/editor` 또는 `@inkio/simple`을 그대로 배치하면 됩니다.

```bash
pnpm add @radix-ui/themes @inkio/editor react react-dom
```

스타일:

```tsx
import '@radix-ui/themes/styles.css';
import '@inkio/editor/style.css';
```

명시적인 라이트·다크 모드라면 Radix Themes의 `appearance`와 Inkio의 `theme`에 같은 `'light'` 또는 `'dark'`를 넘기세요. Radix의 `'inherit'`는 Inkio 값이 아니므로 이 경우 `theme`을 생략하세요. Radix Theme
래퍼 안에만 있는 CSS 변수는 `body`에 열리는 Inkio 포털에 상속되지 않습니다.
