# Tailwind CSS 통합

Tailwind 레이아웃 안에서는 high-level package를 바로 사용하는 편이 가장 단순합니다.

```bash
pnpm add tailwindcss @inkio/simple react react-dom
```

스타일:

```tsx
import '@inkio/simple/style.css';
```

Tailwind의 reset을 먼저 적용하고 Inkio 스타일을 가져오세요. 앱 래퍼는 유틸리티 클래스로
꾸미고, Inkio 내부 색상과 레이어는 [공통 토큰](/components#css-변수와-포털)으로 변경합니다.
