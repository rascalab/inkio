# 이미지 에디터

`@inkio/image-editor`는 자르기, 회전, 크기 조절, 그리기, 도형, 텍스트 주석 기능을 갖춘
독립 이미지 편집기입니다. 에디터의 이미지 블록에 연결하거나 단독 컴포넌트로 사용할 수 있습니다.

## 설치와 CSS

이미지 에디터는 자체 스타일시트가 필요합니다. 앱 진입점에서 한 번 import 하세요.

```tsx
import '@inkio/image-editor/style.css';
```

## 에디터에 연결하기

`@inkio/editor`(또는 `@inkio/simple`)의 `imageBlock.imageEditor` 옵션에 `ImageEditorModal`을
전달하면 이미지 툴바에 편집 버튼이 나타납니다. 버튼을 누르면 모달이 열리고, 저장 시
편집 결과가 해당 이미지 블록에 반영됩니다.

`onImageUpload`가 있으면 편집한 data URL도 `File`로 변환해 같은 콜백으로 업로드하고,
반환된 URL을 저장합니다. 업로드 중에는 원본 문서를 유지하고, 실패하면 원본 이미지를
그대로 두고 `imageBlock.onUploadError` 또는 `onError`로 알립니다. 편집창도 열린 상태로
유지되어 같은 편집 내용을 다시 저장할 수 있습니다. 업로드 중에는 닫기와 추가 편집을
막고, 성공한 뒤 창을 닫습니다. 변경 없이 저장하면 업로드 콜백을 호출하지 않습니다.
콜백을 지정하지 않으면 기존처럼 data URL을 저장합니다.

편집 파일에는 고유한 이름을 부여하며, 같은 편집창에서 재시도할 때는 이름을 재사용합니다.
서버의 저장 키 생성은 앱에서 관리합니다. 미사용 파일은 기본적으로 `immediate` 모드로
정리하며, 아래의 `onDelete`에 실제 스토리지 삭제 함수를 연결합니다.
기본 출력 형식은 PNG입니다. 사진 중심 서비스에서는 `ImageEditorModal`을 감싸
`imageFormat="jpeg"` 또는 `"webp"`를 지정할 수 있습니다.

```tsx
import { Editor } from '@inkio/editor';
import { ImageEditorModal } from '@inkio/image-editor';
import '@inkio/editor/style.css';
import '@inkio/image-editor/style.css';

export function Page() {
  return (
    <Editor
      onImageUpload={async (file) => URL.createObjectURL(file)}
      imageBlock={{
        imageEditor: ImageEditorModal,
        onDelete: (src) => URL.revokeObjectURL(src),
      }}
    />
  );
}
```

`imageEditor`에는 `{ isOpen, imageSrc, onSave, onClose }` 인터페이스를 만족하는 컴포넌트라면
무엇이든 전달할 수 있으며, `ImageEditorModal`이 기본 구현입니다.
사용자 정의 이미지 편집기는 `onSave`가 반환한 Promise를 기다리고, 거절되면 창을
닫지 않아야 합니다.

### 이미지 파일 정리

`imageBlock.cleanup`으로 정리 시점을 선택합니다. `@inkio/editor`와 `@inkio/simple`에서
같은 옵션을 사용하며, `ImageBlock.configure(...)`에도 전달할 수 있습니다.

| 옵션 | 타입 | 기본값 | 동작 |
|------|------|--------|------|
| `cleanup` | `'immediate' \| 'manual'` | `'immediate'` | 미사용 파일을 자동 정리할지 앱이 관리할지 선택합니다. |
| `onDelete` | `(src: string) => void \| Promise<void>` | 없음 | 실제 스토리지에서 URL에 해당하는 파일을 삭제합니다. |

`immediate`에서는 교체나 삭제 후 현재 문서의 마지막 참조가 사라진 이미지에 대해
Inkio가 `onDelete`를 호출합니다. 새 이미지 업로드가 실패하면 이전 이미지를 삭제하지
않습니다. 업로드 중 대상 블록이 삭제되어 결과를 넣지 못한 경우에는 그 업로드 결과를
정리합니다. 같은 URL을 쓰는 이미지가 현재 문서에 남아 있으면 삭제하지 않습니다.

서버 파일을 삭제하려면 `onDelete`를 연결해야 합니다. 이 콜백을 생략하면 Inkio는
스토리지에 삭제 요청을 보내지 않습니다. 위 예제는 임시 blob URL을 해제하며, 서버
스토리지를 쓰는 앱은 자신의 삭제 API를 호출하는 함수로 바꿉니다.

앱이 문서 저장 시점이나 보존 기간에 맞춰 정리하려면 `manual`을 선택하세요.
이 모드에서는 `onDelete`를 지정해도 Inkio가 자동 호출하지 않습니다.

```tsx
<Editor
  onImageUpload={uploadImage}
  imageBlock={{
    imageEditor: ImageEditorModal,
    cleanup: 'manual',
  }}
/>
```

`uploadImage`는 앱에서 구현한 업로드 함수입니다. `immediate`는 실제 파일을 삭제하므로
실행 취소가 이전 파일까지 복원해 주지는 않습니다. 다른 문서와 파일을 공유하거나
문서 저장을 취소할 수 있는 앱에서는 `manual`로 참조와 보존 기간을 관리하세요.

에디터 종료, 읽기 전용 문서 갱신, `setContent`/`clearContent`로 문서 전체를 바꾸는 동작은
자동 삭제로 취급하지 않습니다. 삭제 콜백이 실패하면 `onError`에
`{ source: 'imageBlock.cleanup', recoverable: true }`를 전달하며, 성공한 이미지 교체를
되돌리지는 않습니다.

### `ImageEditorModal` props

| Prop | 타입 | 설명 |
|------|------|------|
| `isOpen` | `boolean` | 모달 열림 여부 (필수) |
| `imageSrc` | `string` | 편집할 이미지 소스 (필수) |
| `onSave` | `(editedImageData: string) => void \| Promise<void>` | 변경한 이미지의 data URL 콜백. 완료 후 닫고, 거절되면 편집 상태를 유지합니다. |
| `onClose` | `() => void` | 닫기 콜백 (필수) |
| `theme` | `'light' \| 'dark'` | 색상 테마 (미지정 시 `.inkio` 루트의 테마를 따름) |
| `imageQuality` | `number` | 출력 품질 0~1 (기본값: `0.92`) |
| `imageFormat` | `'png' \| 'jpeg' \| 'webp'` | 출력 형식 (기본값: `'png'`) |
| `tools` | `ToolType[]` | 노출할 도구 목록 |
| `locale` | `string \| Partial<ImageEditorLocale>` | 로케일 ID 또는 라벨 오버라이드 |
| `messages` | `InkioImageEditorMessageOverrides \| InkioMessageOverrides` | 메시지 오버라이드 |
| `icons` | `Partial<InkioIconRegistry>` | 아이콘 오버라이드 |

## 단독 컴포넌트 사용

모달 없이 인라인 편집 화면을 직접 배치하려면 `ImageEditor`를 사용합니다.

```tsx
import { ImageEditor } from '@inkio/image-editor';
import '@inkio/image-editor/style.css';

export function StandaloneEditor({ src }: { src: string }) {
  return (
    <ImageEditor
      src={src}
      onSave={(dataUrl) => console.log('saved', dataUrl)}
      onCancel={() => console.log('cancelled')}
    />
  );
}
```

### `ImageEditor` props

| Prop | 타입 | 설명 |
|------|------|------|
| `src` | `string` | 편집할 이미지 소스 (필수) |
| `onSave` | `(dataUrl: string) => void \| Promise<void>` | 저장 콜백. 완료를 기다리며, 거절되면 편집 상태를 유지합니다. |
| `onCancel` | `() => void` | 취소 콜백 (필수) |
| `outputFormat` | `'png' \| 'jpeg' \| 'webp'` | 출력 형식 (기본값: `'png'`) |
| `outputQuality` | `number` | 출력 품질 0~1 |
| `tools` | `ToolType[]` | 노출할 도구 목록 |
| `defaultTool` | `ToolType` | 초기 선택 도구 |
| `locale` | `Partial<ImageEditorLocale>` | 라벨 오버라이드 |
| `className` | `string` | 루트 엘리먼트 클래스 |
| `maxUndoSteps` | `number` | 실행 취소 기록 한도 (기본값: `30`) |
| `onDirtyChange` | `(dirty: boolean) => void` | 미저장 변경 발생/해소 콜백 |

## 레이아웃

데스크톱 UI는 세 부분으로 구성됩니다.

- **상단바** — 닫기, 실행 취소/다시 실행, 저장
- **하단 도구 레일** — 활성화된 도구 한 줄 표시
- **Util 패널** — 활성 도구의 옵션 인스펙터 (도구당 1개)

화면 너비에 따라 Util 패널 위치가 바뀝니다.

| 너비 | 배치 |
|------|------|
| 1200px 이상 | 우측 인스펙터 (이미지 영역을 가리지 않음) |
| 901–1199px | 하단 패널 (캔버스가 패널 위로 밀림) |
| 900px 이하 | 모바일 하단 스트립 + 도구 트레이 |

## 도구와 주석

`ToolType`은 다음 도구를 정의합니다.

```ts
type ToolType = 'crop' | 'rotate' | 'resize' | 'draw' | 'shape' | 'text' | 'filter' | 'redact' | 'sticker';
```

- `crop` — 자르기 영역 지정 (resize 패널의 비율 segmented 컨트롤에서 선택)
- `rotate` — 회전 및 좌우/상하 반전
- `resize` — 출력 크기 조절
- `draw` — 자유 그리기 (브러시)
- `shape` — 사각형, 타원, 화살표, 선 도형
- `text` — 텍스트 주석
- `filter` — 프리셋 필터 9종 + 밝기·대비·채도·선명도 미세 조정 (썸네일 미리보기)
- `redact` — 모자이크/블러 영역 지정
- `sticker` — 이모지 스티커 배치

`tools`를 지정하지 않으면 기본 목록(`['resize', 'draw', 'shape', 'text', 'filter', 'redact', 'sticker', 'rotate']`)이 사용됩니다.

```tsx
<ImageEditor src={src} tools={['draw', 'text']} onSave={save} onCancel={cancel} />
```

그리기·도형·텍스트·모자이크·스티커로 추가한 항목은 주석(annotation)으로 관리됩니다.
모든 주석 타입은 `Annotation` 유니온으로 export됩니다.

| 타입 | 설명 |
|------|------|
| `RectAnnotation` | 사각형 도형 |
| `EllipseAnnotation` | 타원 도형 |
| `ArrowAnnotation` | 화살표 |
| `LineAnnotation` | 직선 |
| `TextAnnotationData` | 텍스트 주석 |
| `FreeDrawAnnotation` | 자유 그리기 선 |
| `RedactAnnotation` | 모자이크/블러 영역 (`mode: 'pixelate' \| 'blur'`) |
| `StickerAnnotation` | 이모지 스티커 |

이 외에 `CropRect`, `Transform`, `DrawOptions`, `ShapeOptions`, `TextOptions`,
`ImageEditorState` 등의 보조 타입도 함께 export됩니다.

## i18n

이미지 에디터는 `@inkio/core`와 동일한 메시지 체계를 따릅니다. 도구 라벨 등 UI 텍스트는
다음 헬퍼로 조회·오버라이드합니다.

```tsx
import {
  enImageEditorMessages,
  resolveImageEditorMessages,
  mergeImageEditorMessages,
  toImageEditorMessageOverrides,
} from '@inkio/image-editor';
```

| Export | 설명 |
|--------|------|
| `enImageEditorMessages` | 기본(영어) 메시지 세트 |
| `resolveImageEditorMessages` | 로케일 입력과 오버라이드를 병합해 메시지 세트를 반환 |
| `mergeImageEditorMessages` | 여러 오버라이드를 순서대로 병합 |
| `toImageEditorMessageOverrides` | `InkioMessageOverrides`에서 이미지 에디터 오버라이드를 추출 |

간단히 라벨만 바꾸려면 `ImageEditorModal`/`ImageEditor`의 `locale` prop에
`Partial<ImageEditorLocale>` 객체를 직접 전달해도 됩니다.

```tsx
<ImageEditorModal
  isOpen={isOpen}
  imageSrc={src}
  onSave={onSave}
  onClose={onClose}
  locale={{ save: '저장', cancel: '취소' }}
/>
```
