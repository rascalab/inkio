# Basic React Recipe

`examples/basic-react`는 `@inkio/simple` 기준 예제입니다.

적합한 경우:

- classic WYSIWYG 편집기
- toolbar-first UI
- 가장 작은 React 시작점

실행:

```bash
pnpm install
pnpm --filter example-basic-react dev
```

핵심 포인트:

- `@inkio/simple/style.css`를 진입점에서 앱 CSS보다 먼저 가져옵니다.
- `Editor` wrapper 기본 preset 사용
- 추가 확장이 필요하면 `extensions` prop으로 직접 조합

개발 서버는 저장소의 패키지 소스를 사용합니다. 배포본은 패키지 배포 파일을 사용하므로
저장소 루트에서 먼저 패키지를 빌드한 뒤 예제를 빌드하세요.

```bash
pnpm build:packages
pnpm --filter example-basic-react build
```

`examples/basic-react/dist`를 정적 호스트에 배포합니다. 이 예제의 편집 데이터는
서버에 저장되지 않습니다.
