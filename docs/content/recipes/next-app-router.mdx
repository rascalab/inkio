# Next App Router Recipe

`examples/next-app-router`는 `@inkio/editor` 기준 예제입니다.

적합한 경우:

- notion-like editor
- Next.js App Router
- comments와 image editor를 함께 쓰는 경우

실행:

```bash
pnpm install
pnpm --filter example-next-app-router dev
```

핵심 포인트:

- 편집 콜백과 브라우저 API는 `'use client'` 래퍼 안에서 설정합니다. 서버 페이지도
  직렬화 가능한 초기 문서를 래퍼에 넘길 수 있습니다.
- `Editor`와 프리셋 `Viewer`는 정적 HTML을 먼저 표시하고 hydration 후 인터랙티브
  인스턴스를 마운트합니다. 정적 HTML만 필요하면 `StaticViewer`를 쓰세요.
- `app/layout.tsx`는 `@inkio/editor/style.css`와 `@inkio/image-editor/style.css`를
  앱 스타일보다 먼저 가져옵니다.
- 예제는 클라이언트 래퍼 안에서 `next/dynamic`(`ssr: false`)으로 이미지 모달만
  지연 로드합니다. 본문 에디터의 정적 셸은 그대로 남습니다.

## 프로덕션 빌드

```bash
pnpm build:packages
pnpm --filter example-next-app-router build
pnpm --filter example-next-app-router start
```

저장소의 `dev`·`build:smoke`는 워크스페이스 소스를 사용합니다. `transpilePackages`와
Webpack alias는 이 소스 모드에서만 사용하는 설정입니다. 기본 `build`는 패키지 배포
파일을 사용하므로 npm 패키지를 쓰는 앱에 소스 alias를 복사할 필요는 없습니다.
예제를 기본 설정 그대로 배포하려면 Next.js를 실행할 수 있는 호스트를 사용하세요.
예제의 댓글과 이미지 URL은 메모리에만 있어 새로고침 시 없어집니다.
