# Yjs 실시간 협업 레시피

React 에디터를 로컬 Hocuspocus 서버에 연결하고, 두 탭에서 같은 문서를 편집합니다.
Node.js 24, pnpm 12.10.0, Git, OpenSSL이 필요합니다.

## 1. 로컬 서버 시작하기

첫 번째 터미널에서 inkio `v0.2.1`의 참조 서버를 켭니다.

```bash
git clone --branch v0.2.1 --depth 1 https://github.com/rascalab/inkio.git inkio-v0.2.1
cd inkio-v0.2.1
pnpm install --frozen-lockfile
pnpm --filter example-collab-server build

export DATA_DIR="$(mktemp -d)"
export COLLAB_HOST=127.0.0.1
export PORT=3123
export COLLAB_ROOM_ID=shared-doc
export COLLAB_ALLOWED_ORIGINS=http://127.0.0.1:5173
export COLLAB_EDITOR_TOKEN="$(openssl rand -hex 32)"
printf '%s\n' "$COLLAB_EDITOR_TOKEN"
pnpm --filter example-collab-server start
```

출력된 로컬 토큰은 아래 입력란에만 붙여 넣으세요. 코드, URL, `VITE_*`에는 넣지 않습니다.

## 2. React 클라이언트 만들기

두 번째 터미널에서 inkio 저장소 밖에 Vite 앱을 만듭니다.

```bash
pnpm create vite@latest inkio-yjs-client --template react --no-interactive
cd inkio-yjs-client
pnpm add @inkio/collab@0.2.1 @inkio/core@0.2.1 yjs@^13.6.13
```

`src/main.jsx`를 아래 코드로 교체합니다.

```jsx
import { useState } from 'react';
import { createRoot } from 'react-dom/client';
import { EditorContent, useInkioCollaborativeEditor } from '@inkio/collab';
import '@inkio/core/style.css';

function Room({ token }) {
  const { editor, status, readOnly } = useInkioCollaborativeEditor({
    docId: 'shared-doc',
    url: 'ws://127.0.0.1:3123/collab',
    token,
    content: '<p>공유 문서를 편집해 보세요.</p>',
    ariaLabel: '공유 문서',
  });

  return (
    <div className="inkio inkio-editor inkio-container-default">
      <p role="status">{status}{readOnly ? ' (읽기 전용)' : ''}</p>
      {editor && <EditorContent editor={editor} />}
    </div>
  );
}

function App() {
  const [token, setToken] = useState('');
  return (
    <>
      <form autoComplete="off" onSubmit={event => {
        event.preventDefault();
        const form = event.currentTarget;
        setToken(new FormData(form).get('token'));
        form.reset();
      }}>
        <label>문서 토큰 <input name="token" type="password" required /></label>
        <button type="submit">연결</button>
      </form>
      {token && <Room token={token} />}
    </>
  );
}

createRoot(document.getElementById('root')).render(<App />);
```

앱을 실행합니다.

```bash
pnpm dev --host 127.0.0.1 --port 5173 --strictPort
```

## 3. 두 탭에서 확인하기

두 탭에서 `http://127.0.0.1:5173`(`localhost` 아님)을 열고 같은 토큰으로 연결하세요.
둘 다 `synced`가 되면 한쪽에 입력한 내용이 다른 쪽에 바로 나타납니다.
